## Clase 1: Introducción y primeros pasos

Este script recrea el comando ls de Unix en Node.js: lista los archivos de una carpeta mostrando si son archivos o directorios, su tamaño y la fecha de modificación. Usa `fs/promises` para leer los archivos de forma asíncrona con `async/await`, y `Promise.all()` para procesarlos todos en paralelo. 

```js
const fs = require('node:fs/promises')
const path = require('node:path')
const pc = require('picocolors')

const folder = process.argv[2] ?? '.'

async function ls (folder) {
  let files
  try {
    files = await fs.readdir(folder) // Lista de archivos
  } catch {
    console.error(pc.red(`❌ No se pudo leer el directorio ${folder}`))
    process.exit(1)
  }

  const filesPromises = files.map(async file => {
    const filePath = path.join(folder, file)
    let stats

    try {
      stats = await fs.stat(filePath) // status - información del archivo
    } catch {
      console.error(`No se pudo leer el archivo ${filePath}`)
      process.exit(1)
    }

    const isDirectory = stats.isDirectory()
    const fileType = isDirectory ? 'd' : 'f'
    const fileSize = stats.size.toString()
    const fileModified = stats.mtime.toLocaleString()

    return `${pc.bgMagenta(fileType)} ${pc.blue(file.padEnd(20))} ${pc.green(fileSize.padStart(10))} ${pc.yellow(fileModified)}`
  })

  const filesInfo = await Promise.all(filesPromises)

  filesInfo.forEach(fileInfo => console.log(fileInfo))
}

ls(folder)
```

Como la función que le pasamos a `.map()` es async, cada llamada devuelve una promesa, no el string directamente. Esto significa que filesPromises termina siendo un array de promesas, no de strings:

```js
filesPromises = [
  Promise { <pending> },
  Promise { <pending> },
  Promise { <pending> }
]
```

Por eso, más adelante en el código, es necesario hacer:

```js
const filesInfo = await Promise.all(filesPromises)
```

> `Promise.all()` espera a que todas las promesas del array se resuelvan y devuelve un nuevo array con los valores reales (los strings ya formateados), en lugar de las promesas pendientes.
